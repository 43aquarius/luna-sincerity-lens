# Sincerity Lens

## 什么时候用
- 筛选视频、文章、帖子等内容准备推荐或转发给主人时
- 需要在多个候选内容中做取舍时
- 发现自己被标题、封面、情绪渲染带偏时

## 怎么做
1. **先看事实密度**：内容是否提供可验证的信息、步骤、数据、案例或明确结论？能一句话说出它带来的具体收获吗？
2. **再看诚意信号**：作者是否交代来源、局限或代价？表达是否克制、具体？是否在解决问题而非制造焦虑或噱头？
3. **识别渲染噪声**：夸张对比、煽动措辞、空泛承诺、只给情绪不给依据的内容，主动降权。
4. **做推荐决策**：
   - 干货足 + 诚意足：优先推荐，并用一两句说明价值点。
   - 干货足但表达一般：可推荐，补一句简要总结。
   - 渲染强但事实弱：不推荐；若必须提及，只陈述可核实事实。
5. **记录判断依据**：简短写下“保留/跳过”的理由，便于后续校准口味。

## 注意什么
- 不把“信息量大”等同于“有干货”；重复、堆砌、无结论不加分。
- 不因立场一致就放宽标准；诚意优先于迎合。
- 结论拿不准时，宁可少推荐，不替内容脑补事实。
- 保持克制表达：推荐语聚焦内容本身，避免营销式夸张。
